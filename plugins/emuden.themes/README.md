# Themes

Ten more colour themes for the whole of EmuDEN, beside its own Light, Dark and the others.
Pick one under Settings, Display, "Theme". Tapping the plugin on the Plugins screen opens that
setting. If the plugin is removed, EmuDEN goes back to Light.

| Theme | Look |
|---|---|
| Void | pure black for OLED screens, soft white text |
| Deep Harbor | deep midnight blue, sky-blue selection |
| Fernwood | dark forest green, leaf-green selection |
| Ember Dusk | warm dark red-brown, orange selection |
| Lavender Night | dark violet, lilac selection |
| Glacier | cool slate grey, pale ice-blue selection |
| Signal | black with yellow text: high contrast |
| Parchment | light paper sepia with brown ink |
| Cloud | soft light grey-white with navy text |
| Pocket Green | light olive with dark green text, like an old handheld's screen |

Every theme's text and secondary text reach at least 4.5:1 contrast on its page, and its
selection colour at least 3:1. Sizes stay EmuDEN's own.

It holds no code: EmuDEN reads the colours from `plugin.json`. See `docs/themes.md`.
